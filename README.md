# Torensa

Torensa is a lightweight web-based SaaS tool designed to help users manage and streamline their workflow efficiently.  
(It focuses on simplicity, speed, and usability.)

---

## 🚀 Features

- Simple and clean user interface
- Fast and lightweight performance
- Easy setup and usage
- Cloud-ready architecture
- Designed for scalability
